# Optionale Modellbewertung

Diese Skripte gehören nicht zur eigentlichen 50k-Hauptpipeline. Sie
dokumentieren die ergänzende Pilotannotation, die Erstellung und Prüfung der
450er Evaluationsbasis sowie den Vergleich mit dem vortrainierten Modell.

Die Hauptanalyse funktioniert mit den sieben Python-Skripten direkt im Ordner
`scripts/`. Die Skripte in diesem Unterordner werden nur benötigt, wenn die
Annotation oder Modellbewertung erneut durchgeführt werden soll.
